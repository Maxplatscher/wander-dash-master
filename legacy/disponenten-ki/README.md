# Easy Planning

Easy Planning ist eine operative Tourenplanungs- und Leitstellenlösung für Dispositionsteams mit Fahreranbindung.  
Das Produkt richtet sich an Admins, Dispatcher und Fahrer, die tägliche Planung und Ausführung in einem Ablauf steuern.  
Besonders ist die Kombination aus Tagesleitstelle, Versionsvergleich, Problemlisten und direkter Driver-View.  
So werden Planung, Freigabe und operative Umsetzung in einem konsistenten Dashboard verbunden.
